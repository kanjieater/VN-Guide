# VN Guide

VN Guide turns Japanese visual-novel and explicitly opted-in linear-game walkthroughs into mobile-friendly, route-by-route guides with local progress tracking.

**Live site:** [kanjieater.github.io/VN-Guide](https://kanjieater.github.io/VN-Guide/)

## Agent workflow

Agents work directly against the repository and pull requests. There is no local autonomous model runner.

Start with [AGENTS.md](AGENTS.md), then follow the canonical material in [agents/](agents/):

- [Guide standards](agents/guide-standards.md)
- [Guide author](agents/guide-author.md)
- [Structural reviewer](agents/guide-reviewer-structural.md)
- [Accuracy reviewer](agents/guide-reviewer-accuracy.md)
- [Review workflow](agents/guide-review.md)

Author, structural-review, and accuracy-review work stay in independent contexts. A guide is complete only when both review gates are clean for the current content and every route is marked `reviewed: true`.

## Deterministic generation

Only mechanical repository output is generated by code:

```bash
bun run generate
```

This synchronizes the landing page and per-game bootstrap/manifest files from `games.json` and [templates/](templates/). The Bun test suite rejects stale generated artifacts; `bun run generate:check` is also available as a focused local check.

Research, guide authoring, corrections, and reviews are agent work, not generator-script work.

## Tests and coverage

The repository uses Bun for dependency installation, test execution, and coverage:

```bash
bun install
bun test
bun run test:coverage
```

Tests are use-case driven. Bun's native `--parallel` mode gives every test file a fresh global while scheduling files across CPU cores; independent tests within a file may additionally run concurrently with a maximum concurrency of 20. They exercise reader resume/navigation, route transitions, spoiler behavior, bad-end/load handling, flowchart preview/commit and zoom interactions, detailed sidecar topology, landing-page progress filtering, and deterministic generation.

CI reports whole-code coverage and enforces **100% changed-line coverage** for executable application/generator code.
